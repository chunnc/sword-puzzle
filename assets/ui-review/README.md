# UI review captures

`after/1080x1920/` and `after/1080x2340/` contain Unity Game View captures of map, exploration, battle, boss, breakthrough, win, loss, and account screens. The Unity Editor capture command checks each PNG's exact dimensions and rejects blank frames.

`before/` preserves the two references supplied for this review. The exploration reference is a cropped top section rather than a full-screen capture.
